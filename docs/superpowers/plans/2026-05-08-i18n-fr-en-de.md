# Portfolio i18n (FR / EN / DE) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrer le portfolio mono-langue (FR) vers une expérience trilingue FR / EN / DE avec routes localisées, switcher de langue, et SEO multilingue propre.

**Architecture:** Adoption de `next-intl` sur Next.js 16 App Router. Routes sous `[locale]` avec `localePrefix: "always"` (toutes les URLs préfixées : `/fr`, `/en`, `/de`). Routes traduites via `pathnames` (`/fr/a-propos` ↔ `/en/about` ↔ `/de/uber-mich`, etc.). Contenu textuel migré de `src/content/*.ts` vers `src/messages/{fr,en,de}.json`, structure non-traduisible (IDs, hrefs, image paths, edges du graphe stack) reste dans `src/content/*.ts`. Switcher de langue : segmented control avec drapeaux 🇫🇷 🇬🇧 🇩🇪 dans la nav top-right + liens dans le footer. SEO : `alternates.languages` dans metadata, sitemap multilingue avec hreflang, JSON-LD localisé.

**Tech Stack:** Next.js 16 App Router, TypeScript, next-intl ^4 (RSC-first, App Router), Tailwind CSS v4, oxlint/oxfmt.

## Décisions verrouillées (issues du brainstorming)

- **Lib** : `next-intl` (RSC support natif, ecosystem mûr)
- **URL strategy** : `localePrefix: "always"` — `/fr/...`, `/en/...`, `/de/...` (aucune locale par défaut au root `/`)
- **Routes traduites** : `pathnames` config — les URLs reflètent la langue (`/en/about`, `/de/uber-mich`)
- **Détection** : middleware next-intl (Accept-Language header → cookie `NEXT_LOCALE` ensuite)
- **Switcher** : segmented control `🇫🇷 FR | 🇬🇧 EN | 🇩🇪 DE` dans nav top-right + liens dans footer
- **Captions galerie** : traduites (FR `Brésil` → EN `Brazil` → DE `Brasilien`)
- **Mobile** : pas de cache derrière burger, switcher visible direct
- **Traductions** : agent propose, user valide

- [ ] **Step 2.2: Créer `src/app/[locale]/layout.tsx`**

```tsx
import { NextIntlClientProvider, hasLocale } from "next-intl";
import { setRequestLocale, getMessages, getTranslations } from "next-intl/server";
import { notFound } from "next/navigation";
import type { Metadata } from "next";
import { routing, type Locale } from "@/i18n/routing";
import { getBaseUrl } from "@/utils/siteUrl";
import { siteContent } from "@/content/site";

const baseUrl = getBaseUrl();

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export async function generateMetadata({
  params,
}: {
  params: Promise<{ locale: Locale }>;
}): Promise<Metadata> {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: "metadata" });
  const title = t("siteTitle");
  const description = t("siteDescription");
  return {
    metadataBase: new URL(baseUrl),
    title: { default: title, template: `%s | ${siteContent.ownerName}` },
    description,
    alternates: {
      canonical: `/${locale}`,
      languages: {
        fr: "/fr",
        en: "/en",
        de: "/de",
      },
    },
    openGraph: {
      type: "website",
      locale: localeToOg(locale),
      url: `${baseUrl}/${locale}`,
      siteName: title,
      title,
      description,
      images: [{ url: "/hero-1.jpeg", width: 1200, height: 630, alt: siteContent.heroImage.alt }],
    },
    twitter: {
      card: "summary_large_image",
      title,
      description,
      images: [{ url: "/hero-1.jpeg", alt: siteContent.heroImage.alt }],
    },
  };
}

function localeToOg(locale: Locale): string {
  return { fr: "fr_FR", en: "en_US", de: "de_DE" }[locale];
}

type LocaleLayoutProps = Readonly<{
  children: React.ReactNode;
  params: Promise<{ locale: Locale }>;
}>;

export default async function LocaleLayout({ children, params }: LocaleLayoutProps) {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) notFound();
  setRequestLocale(locale);

  const messages = await getMessages();
  const t = await getTranslations({ locale, namespace: "metadata" });

  const personJsonLd = {
    "@context": "https://schema.org",
    "@type": "Person",
    name: siteContent.ownerName,
    jobTitle: t("siteTitle"),
    description: t("siteDescription"),
    image: `${baseUrl}/hero-1.jpeg`,
    url: `${baseUrl}/${locale}`,
  };

  const websiteJsonLd = {
    "@context": "https://schema.org",
    "@type": "WebSite",
    name: t("siteTitle"),
    description: t("siteDescription"),
    url: `${baseUrl}/${locale}`,
    inLanguage: locale,
    publisher: { "@type": "Person", name: siteContent.ownerName },
  };

  return (
    <NextIntlClientProvider messages={messages} locale={locale}>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify([personJsonLd, websiteJsonLd]),
        }}
      />
      {children}
    </NextIntlClientProvider>
  );
}
```

import { cookies, headers } from "next/headers";

export default async function RootLayout({ children }: RootLayoutProps) {

```tsx
"use client";

import { useTransition } from "react";
import { useLocale, useTranslations } from "next-intl";
import { useRouter, usePathname } from "@/i18n/navigation";
import { routing, type Locale } from "@/i18n/routing";
import { cn } from "@/lib/utils";

const LOCALE_FLAGS: Record<Locale, string> = {
  fr: "🇫🇷",
  en: "🇬🇧",
  de: "🇩🇪",
};

const LOCALE_LABELS: Record<Locale, string> = {
  fr: "FR",
  en: "EN",
  de: "DE",
};

export function LanguageSwitcher({ className }: { className?: string }): React.JSX.Element {
  const t = useTranslations("languageSwitcher");
  const router = useRouter();
  const pathname = usePathname();
  const currentLocale = useLocale() as Locale;
  const [isPending, startTransition] = useTransition();

  function switchTo(nextLocale: Locale) {
    if (nextLocale === currentLocale) return;
    startTransition(() => {
      router.replace(pathname, { locale: nextLocale });
    });
  }

  return (
    <div
      role="group"
      aria-label={t("ariaLabel")}
      className={cn(
        "inline-flex items-center gap-0.5 rounded-full border border-border bg-background/60 p-0.5 backdrop-blur-sm",
        className,
      )}
    >
      {routing.locales.map((locale) => {
        const active = locale === currentLocale;
        return (
          <button
            key={locale}
            type="button"
            disabled={isPending}
            aria-label={t(locale)}
            aria-current={active ? "true" : undefined}
            onClick={() => switchTo(locale)}
            className={cn(
              "inline-flex items-center gap-1 rounded-full px-2.5 py-1 text-xs font-medium transition",
              active
                ? "bg-foreground text-background"
                : "text-muted-foreground hover:text-foreground",
              isPending && "opacity-50 cursor-not-allowed",
            )}
          >
            <span aria-hidden="true">{LOCALE_FLAGS[locale]}</span>
            <span>{LOCALE_LABELS[locale]}</span>
          </button>
        );
      })}
    </div>
  );
}
```

## Notes & gotchas anticipés

1. **`localePrefix: "always"` + redirect root** : avec cette config, `/` redirige automatiquement vers `/fr` (defaultLocale). Le middleware s'en occupe.

2. **`<html lang>` dynamique** : Next.js 16 ne permet pas de lire le params `[locale]` depuis `app/layout.tsx` root. Workaround : lire la cookie `NEXT_LOCALE` côté server (Step 2.4). Pas idéal, mais acceptable. Alternative future : restructurer pour que `[locale]/layout.tsx` ait son propre `<html>` (mais Next 16 n'aime pas ça).

3. **Static rendering** : `setRequestLocale(locale)` doit être appelé en haut de chaque page server pour rendu statique. Sans ça, Next bascule en dynamic.

4. **Nodes du stack-graph** : `level` reste en data ("Notions"/"Intermédiaire"/"Avancé"/"Expert"). C'est une enum FR. Si tu préfères passer à des codes neutres ("BASICS"/"INTERMEDIATE"/"ADVANCED"/"EXPERT"), faire ce refactor en parallèle dans Task 3.

5. **Pathnames map** : `/de/uber-mich` utilise "uber" sans umlaut pour éviter les problèmes URL (URL-safe). Si tu veux "über-mich" avec umlaut → ok mais teste l'encoding.

6. **Galerie "alt"** : actuellement `alt` = `caption` partout. On utilise `t("gallery.captions.<id>")` pour les deux. Si besoin de différencier (description plus riche en alt vs caption courte), ajouter `t("gallery.alts.<id>")`.

7. **Niveaux stack** : "Notions" → EN "Basics" / DE "Grundkenntnisse" → traduits via `t("stack.levels.Notions")`. Le niveau stocké en data reste "Notions" (clé canonique FR). Si gênant, refactor en codes neutres (cf. note 4).

8. **Cookie `NEXT_LOCALE`** : géré automatiquement par next-intl middleware. Pas de code custom à écrire.

9. **Build size** : next-intl ajoute ~30kB minified gzipped. Acceptable.

10. **Test runner** : projet sans test runner configuré (CLAUDE.md). Plan utilise `npx tsc --noEmit`, `npm run build`, et tests manuels comme verification gates.

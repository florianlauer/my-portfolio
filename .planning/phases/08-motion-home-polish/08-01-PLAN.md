# Phase 8 — Plan 08-01: HomeNav Indicator Slide + ScrollProgressBar

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Faire glisser un indicateur visuel entre les items actifs du HomeNav au scroll-spy, et ajouter une progress bar fine en haut de viewport reflétant la progression du scroll. Les deux respectent `prefers-reduced-motion`.

**Architecture:** L'indicateur HomeNav est un `<div>` absolument positionné à l'intérieur de la `<nav>` (qui devient `relative`). Sa position (`translate`) et sa taille (`width`/`height`) sont calculées en lisant le `getBoundingClientRect()` du link actif et stockées via styles inline mutés (1 élément, 0 re-render). Recalcul déclenché par : changement de `activeKey`, scroll horizontal de la nav (taille du nav change avec le scroll vertical), scroll vertical (qui anime padding des links), resize. La transition CSS sur `transform/width/height` fait le slide. `motion-reduce:` désactive la transition. La `ScrollProgressBar` est un nouveau composant client `fixed top-0` qui mute `transform: scaleX(ratio)` sur un `<div>` enfant via rAF dans un `useEffect` (pas de state React → 0 re-render au scroll).

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind v4. Pas de dépendance ajoutée (`motion` reste utilisée par `HeroImageParallax` mais pas ici — CSS suffit).

### Step 3: Add the indicator position effect

Insère ce `useEffect` juste après le `useEffect` de "Détection section active au scroll" (après la ligne 82, avant `const isHome = ...`) :

```tsx
// Slide indicator under the active link. Mutates inline styles directly
// to avoid re-renders on every scroll/resize tick.
useEffect(() => {
  const nav = navRef.current;
  const indicator = indicatorRef.current;
  if (!nav || !indicator) return;

  const update = (): void => {
    if (!activeKey) {
      indicator.style.opacity = "0";
      return;
    }
    const target = linkRefs.current.get(activeKey);
    if (!target) {
      indicator.style.opacity = "0";
      return;
    }
    const navRect = nav.getBoundingClientRect();
    const tRect = target.getBoundingClientRect();
    const x = tRect.left - navRect.left + nav.scrollLeft;
    const y = tRect.top - navRect.top + nav.scrollTop;
    indicator.style.transform = `translate(${x}px, ${y}px)`;
    indicator.style.width = `${tRect.width}px`;
    indicator.style.height = `${tRect.height}px`;
    indicator.style.opacity = "1";
  };

  let rafId: number | null = null;
  const schedule = (): void => {
    if (rafId !== null) return;
    rafId = requestAnimationFrame(() => {
      rafId = null;
      update();
    });
  };

  // Initial position on first paint (after refs registered).
  update();

  nav.addEventListener("scroll", schedule, { passive: true });
  window.addEventListener("scroll", schedule, { passive: true });
  window.addEventListener("resize", schedule, { passive: true });

  // Recompute when an item's box itself changes size (nav padding/link
  // padding shrink with scroll progress -- the active link's width changes).
  const ro = new ResizeObserver(schedule);
  linkRefs.current.forEach((el) => ro.observe(el));

  return () => {
    nav.removeEventListener("scroll", schedule);
    window.removeEventListener("scroll", schedule);
    window.removeEventListener("resize", schedule);
    ro.disconnect();
    if (rafId !== null) cancelAnimationFrame(rafId);
  };
}, [activeKey]);
```

### Step 1: Write the new component

- [ ] Crée le fichier `src/components/scroll-progress/ScrollProgressBar.tsx` avec ce contenu exact :

```tsx
"use client";

import { useEffect, useRef } from "react";

/**
 * Fine progress bar fixed at the top of the viewport.
 * Width fill = scrollY / (scrollHeight - innerHeight).
 *
 * Mutates `transform: scaleX(ratio)` on a child element directly via rAF.
 * No React state → 0 re-renders during scroll. The transform is GPU-composited.
 *
 * `prefers-reduced-motion: reduce` : the bar stays visible (still updates on
 * scroll), but no CSS transition is applied. Behaviour is identical because
 * we don't transition the transform anyway -- rAF on the actual scrollY value
 * is smooth enough without an interpolation layer.
 */
export function ScrollProgressBar(): React.JSX.Element {
  const fillRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const fill = fillRef.current;
    if (!fill) return;

    let rafId: number | null = null;

    const update = (): void => {
      rafId = null;
      const doc = document.documentElement;
      const max = doc.scrollHeight - window.innerHeight;
      const ratio = max > 0 ? Math.min(1, Math.max(0, window.scrollY / max)) : 0;
      fill.style.transform = `scaleX(${ratio})`;
    };

    const schedule = (): void => {
      if (rafId !== null) return;
      rafId = requestAnimationFrame(update);
    };

    update();
    window.addEventListener("scroll", schedule, { passive: true });
    window.addEventListener("resize", schedule, { passive: true });

    // Page height can change without a scroll/resize (images load, sections
    // mount). Observe the body so the ratio stays accurate.
    const ro = new ResizeObserver(schedule);
    ro.observe(document.body);

    return () => {
      window.removeEventListener("scroll", schedule);
      window.removeEventListener("resize", schedule);
      ro.disconnect();
      if (rafId !== null) cancelAnimationFrame(rafId);
    };
  }, []);

  return (
    <div
      className="pointer-events-none fixed left-0 right-0 top-0 z-40 h-[2px] bg-transparent"
      aria-hidden
    >
      <div
        ref={fillRef}
        className="h-full w-full origin-left bg-primary will-change-transform"
        style={{ transform: "scaleX(0)" }}
      />
    </div>
  );
}
````

Notes :

- `h-[2px]` = 2px exactement (line fine, non intrusive).
- `z-40` au-dessus du HomeNav `z-30`. Aria-hidden : élément purement visuel.
- `origin-left` = `transform-origin: left center` → la barre se remplit de gauche à droite avec `scaleX`.
- Pas de `transition` CSS : le rAF binding sur `window.scrollY` produit déjà ~60fps fluide.

# Phase 6 — Plan 06-01: Responsive layout / version simplifiée

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre le Stack Graph utilisable sur mobile (viewport ≤ 768px) sans débordement, avec des nœuds dimensionnés au format compact, une légende positionnée hors du SVG sur mobile, et un layout qui n'écrase plus les contrôles.

**Architecture:** Le `StackGraph` dérive un flag `isCompact` à partir de `size.width` (déjà tracké via `ResizeObserver`). Un `radiusScale` (1 sur desktop, 0.7 sur compact) est passé à `GraphNode` et `useForceLayout` — les rayons visuels et de collision sont multipliés à la volée, la simulation d3-force a plus de marge pour positionner les 39 nœuds dans un viewBox plus étroit. La `MIN_TOUCH_RADIUS` (44×44 WCAG) reste constante : la zone de hit ne rétrécit jamais sous le seuil tactile. La légende est extraite du conteneur SVG sur mobile et rendue en flow document sous le graph, pour ne plus chevaucher les nœuds. Les filter pills wrapent déjà (`flex-wrap`) — pas de changement nécessaire.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind v4. Pas de nouvelle dépendance. Detection compact côté JS (via `size.width`) + Tailwind responsive utilities (`md:`) côté CSS pour le placement de la légende.

function buildSimulation(
  simNodes: SimNode[],
  simEdges: SimEdge[],
  width: number,
  height: number,
  alpha: number,
  radiusScale: number,
): Simulation<SimNode, SimEdge> {
  return forceSimulation<SimNode>(simNodes)
    .force("center", forceCenter(width / 2, height / 2))
    .force("charge", forceManyBody<SimNode>().strength(FORCE_CONFIG.charge))
    .force(
      "link",
      forceLink<SimNode, SimEdge>(simEdges)
        .id((d) => d.id)
        .distance(FORCE_CONFIG.linkDistance)
        .strength(FORCE_CONFIG.linkStrength),
    )
    .force(
      "collide",
      forceCollide<SimNode>()
        .radius((d) => (COLLIDE_RADIUS_BY_LEVEL[d.level] ?? 28) * radiusScale)
        .strength(FORCE_CONFIG.collideStrength)
        .iterations(FORCE_CONFIG.collideIterations),
    )
    .force("x", forceX<SimNode>(width / 2).strength(FORCE_CONFIG.positionStrength))
    .force("y", forceY<SimNode>(height / 2).strength(FORCE_CONFIG.positionStrength))
    .alpha(alpha)
    .alphaDecay(FORCE_CONFIG.alphaDecay)
    .velocityDecay(FORCE_CONFIG.velocityDecay);
}

  <name>Task 1: Create force layout hook, micro-movement hook, and StackGraph orchestrator</name>
  <files>src/components/stack-graph/use-force-layout.ts, src/components/stack-graph/use-micro-movement.ts, src/components/stack-graph/StackGraph.tsx, src/components/stack-graph/GraphNode.tsx, src/app/stack/page.tsx</files>
  <action>
1. Create `src/components/stack-graph/use-force-layout.ts`:
   - "use client" is NOT needed (hooks are used by client components, not declared as standalone client modules)
   - Define `SimNode` type: `GraphNode & { x: number; y: number; vx: number; vy: number; index?: number }`
   - Define `SimEdge` type: `{ source: string | SimNode; target: string | SimNode }` (d3-force mutates source/target from string to object)
   - Hook signature: `useForceLayout(nodes: GraphNode[], edges: GraphEdge[], width: number, height: number)`
   - Returns: `{ positions: SimNode[]; isStabilized: boolean }`
   - Implementation:
     a. Clone nodes on init: `nodes.map(n => ({ ...n, x: width/2 + (Math.random()-0.5)*100, y: height/2 + (Math.random()-0.5)*100, vx: 0, vy: 0 }))`
     b. Create simulation with `forceSimulation`, `forceCenter(width/2, height/2)`, `forceManyBody().strength(-250)`, `forceLink(clonedEdges).id(d => d.id).distance(120).strength(0.4)`, `forceCollide().radius(40)`
     c. Set `alpha(1)`, `alphaDecay(0.02)`, `velocityDecay(0.3)` for visible ~1.5s animation
     d. On each `tick`: `setPositions([...simNodes])` to trigger React re-render
     e. On `end` event: set `isStabilized = true`
     f. Store simulation in `useRef` to avoid recreation. Only create when width/height > 0
     g. Cleanup: `sim.stop()` in useEffect return
     h. Memoize/guard against re-runs: only recreate simulation if nodes.length or width/height change meaningfully

2. Create `src/components/stack-graph/use-micro-movement.ts`:
   - Hook signature: `useMicroMovement(nodeCount: number, isStabilized: boolean, prefersReducedMotion: boolean)`
   - Returns: `offsets: { dx: number; dy: number }[]` — per-node x/y offsets to add to base positions
   - Implementation:
     a. If `prefersReducedMotion` or `!isStabilized`: return array of `{ dx: 0, dy: 0 }`
     b. Use `useRef` to store per-node random phase offsets (generated once): `Math.random() * Math.PI * 2` for each node
     c. Use `requestAnimationFrame` loop (started when `isStabilized` becomes true):
     - For each node: `dx = Math.sin(time * 0.001 + phase) * 2`, `dy = Math.cos(time * 0.0007 + phase) * 1.5`
     - Amplitude: ~2px horizontal, ~1.5px vertical (subtle floating)
     - Each node has a slightly different speed via the phase offset
       d. Update `offsets` state at ~30fps (throttle with timestamp check, not every rAF)
       e. Cleanup: cancel rAF on unmount

3. Update `src/components/stack-graph/GraphNode.tsx` (from Plan 01):
   - Wrap the existing SVG `<g>` in `motion.g` from the `motion` package for drag support
   - Add drag props: `drag`, `dragMomentum={false}`, `dragElastic={0}`
   - Use `style={{ x: props.x, y: props.y }}` for positioning (motion values)
   - On drag end: animate back to base position with `transition={{ type: "spring", stiffness: 300, damping: 15 }}` for the bouncy return effect
   - Accept new optional props: `isDragging?: boolean`, `onDragStart?: () => void`, `onDragEnd?: () => void`
   - During drag: slightly increase glow intensity (scale filter radius from 8px to 12px)
   - The component must be marked `"use client"` since it now uses motion

4. Create `src/components/stack-graph/StackGraph.tsx` ("use client"):
   - Props: `{ data: StackGraph }`
   - Use `useRef` + `ResizeObserver` to get container width/height dynamically
   - Call `useForceLayout(data.nodes, data.edges, width, height)` to get positions
   - Call `useReducedMotion()` from `motion` for reduced-motion detection
   - Call `useMicroMovement(data.nodes.length, isStabilized, prefersReducedMotion)` for float offsets
   - Build a color lookup: `Map<StackFamilyKey, string>` from `data.familyColors`
   - Render structure:
     ```
     <div ref={containerRef} className="relative w-full h-full min-h-[60vh]">
       <svg viewBox={`0 0 ${width} ${height}`} className="w-full h-full">
         <g>{edges mapped to <GraphEdge>}</g>
         <g>{nodes mapped to <GraphNode> with positions + micro-movement offsets}</g>
       </svg>
       <GraphLegend familyColors={data.familyColors} />
     </div>
     ```
   - Edge rendering: for each edge, find source and target positions from the positions array. Use a Map<string, SimNode> for O(1) lookup by node ID
   - Node rendering: for each position, add micro-movement offset (`pos.x + offsets[i].dx`, `pos.y + offsets[i].dy`), pass family color from lookup
   - SVG should have `overflow="visible"` to handle nodes near edges

5. Update `src/app/stack/page.tsx`:
   - Replace the placeholder `<div id="stack-graph-root">` with `<StackGraph data={stackGraph} />`
   - Import `StackGraph` from `@/components/stack-graph/StackGraph`
   - Import `stackGraph` from `@/content/stack-graph`
   - Keep it as a Server Component — StackGraph is a Client Component imported by a Server Component (standard Next.js pattern)

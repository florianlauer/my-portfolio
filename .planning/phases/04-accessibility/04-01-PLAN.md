   - Add `reducedMotion: boolean` as 5th parameter to `useForceLayout`
   - In the init `useEffect` (line ~58), AFTER creating the simulation and forces:
     - If `reducedMotion` is true:
       - Call `sim.stop()` immediately
       - Run `while (sim.alpha() > sim.alphaMin()) { sim.tick(); }` to compute final layout synchronously
       - Apply the same bounds-clamping (padding=40) to all nodes after convergence
       - Call `setPositions([...nodesRef.current])` once
       - Do NOT assign `simRef.current = sim` (leave it null — disables drag)
     - If `reducedMotion` is false: keep existing behavior (tick handler + simRef assignment)
   - In `filterNodes` callback:
     - After updating sim nodes and link force, check if `simRef.current` is null (reduced-motion)
     - If null: create a temporary simulation with same forces, run sync ticks to convergence, setPositions once
     - If not null: keep existing `sim.alpha(0.5).restart()` behavior
   - Drag handlers (`dragStart`, `dragMove`, `dragEnd`) already guard `if (!sim) return` so they naturally no-op when `simRef.current` is null — no changes needed
